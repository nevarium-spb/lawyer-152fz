# Приказ не составлен

Часть 1 статьи 22.1 Закона обязывает назначить ответственного за организацию обработки персональных данных оператора, являющегося юридическим лицом. По ИНН 500100732259 оператор не юридическое лицо (у юридических лиц ИНН из десяти цифр), поэтому шаблон приказ не составляет.

Если вы всё же хотите назначить такое лицо добровольно, составьте приказ самостоятельно; настоящий документ этого не заменяет.
