# @lawyer-152fz/mcp-server

MCP-сервер по 152-ФЗ «О персональных данных» и работе с Роскомнадзором. Для Claude Desktop, Cursor и других MCP-клиентов; в Claude Code удобнее ставить [плагин](https://github.com/nevarium-spb/lawyer-152fz#установка): в нём есть ещё субагент и скиллы.

Нужен Node.js ≥ 26. База норм и шаблоны документов вшиты в пакет, при запуске сеть нужна только инструментам `check_norm_freshness` и `audit_site`.

## Подключение

Конфигурация MCP-клиента:

```json
{
  "mcpServers": {
    "lawyer-152fz": {
      "command": "npx",
      "args": ["-y", "@lawyer-152fz/mcp-server"]
    }
  }
}
```

## Инструменты

| Инструмент                | Назначение                                                        |
| ------------------------- | ----------------------------------------------------------------- |
| `search_norms`            | поиск по нормам                                                   |
| `get_norm`                | полный текст нормы с датой редакции — единственный источник цитат |
| `check_norm_freshness`    | сверка редакции с официальным порталом                            |
| `audit_site`              | обход сайта и проверка форм, согласий, политики, HTTPS, сервисов  |
| `audit_html`              | проверка страницы по DOM из браузера                              |
| `audit_codebase`          | поиск иностранных SDK, зарубежных облаков и ПДн в логах           |
| `list_document_templates` | шаблоны документов, их основания и обязательные поля              |
| `render_document`         | заполнение шаблона данными оператора                              |

Подробности, правила аудита и ограничения — в [репозитории](https://github.com/nevarium-spb/lawyer-152fz).
