# Changesets

Каждое изменение, которое попадёт в релиз, сопровождается записью:

```bash
pnpm changeset
```

Выберите пакеты, тип изменения (patch / minor / major по SemVer) и опишите изменение по-русски.
При релизе записи превращаются в номера версий и CHANGELOG. Подробнее — [PLAN.md](../docs/PLAN.md), веха M8.
