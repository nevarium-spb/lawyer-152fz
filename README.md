# Lawyer 152-FZ

ИИ-юрист по 152-ФЗ «О персональных данных» и работе с Роскомнадзором — плагин для Claude Code и MCP-сервер.

> 🚧 Проект на этапе проектирования. См. [архитектуру](docs/ARCHITECTURE.md) и [решения (ADR)](docs/ARCHITECTURE.md#13-реестр-решений-adr).

## Что будет уметь

- **Аудит сайта и кода**: формы без согласия, cookie и счётчики, трансграничная передача, локализация баз, политика на сайте.
- **Документы**: политика обработки ПДн, согласия, уведомления в РКН.
- **Консультации** со ссылками на конкретные нормы и даты их редакций.

## Установка (после первого релиза)

```
/plugin marketplace add nevarium-spb/lawyer-152fz
/plugin install lawyer-152fz@lawyer-152fz
```

## Важно

Результаты агента носят справочный характер и не заменяют консультацию юриста.
