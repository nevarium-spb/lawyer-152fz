# ADR-0011. Источник норм — API актуальных редакций официального портала

- Статус: принято
- Дата: 2026-10-25
- Закрывает риск R2 и спайк S2 (выполнен досрочно, в вехе M2)

## Контекст

База норм должна содержать официальные тексты в действующей редакции (ADR-0003, ADR-0007).
Проверено 2026-10-25:

- `pravo.gov.ru` (ИПС) и HTTPS у `actual.pravo.gov.ru` из нашей сети недоступны (таймаут).
- `actual.pravo.gov.ru` — «Тексты правовых актов с внесенными изменениями» официального портала правовой информации —
  работает по HTTP и имеет JSON-API, которым пользуется его собственный интерфейс:
  - `attrsearch/?bpa=ebpi&q=…` — поиск акта по номеру и названию;
  - `redactions/?bpa=ebpi&t={"hash":…}` — список редакций с датами и признаком «актуальная»;
  - `redtext?bpa=ebpi&t=<redid>&ttl=0` — HTML текста редакции.
- В этой базе — акты с изменениями после 01.07.2022. ПП РФ № 1119 (2012, не менялся) в ней отсутствует;
  его официальный текст есть на `publication.pravo.gov.ru` (PDF официального опубликования).
- Коммерческие системы (КонсультантПлюс, Гарант) доступны, но не являются официальным источником.

## Решение

- Тексты 152-ФЗ, ст. 13.11 КоАП и ПП № 687 загружаются скриптом `pnpm kb:import` из API `actual.pravo.gov.ru`.
  Ответы API проверяются схемами zod как недоверенные данные.
- Официальность источника определяется **доменом** из белого списка (`pravo.gov.ru` и поддомены, `kremlin.ru`,
  `government.ru`, `rkn.gov.ru`), а не протоколом: официальный портал работает только по HTTP.
- `sourceUrl` нормы — ссылка на документ для людей: `http://actual.pravo.gov.ru/content/content.html#hash=<docHash>`.
- Особенности разметки портала учтены в разборе:
  `W9` — надстрочный индекс («10¹» → `10.1`), `mark`/`markx`/класс `P` — пометки о редакциях (в `notes`, не в текст),
  класс `Y` — подпись (конец текста), «Примечания» к статьям КоАП не нарезаются на части.
- Сверка (решение владельца): автоматическая загрузка + выборочная ручная проверка 3–5 статей против сайта.
  Проверяется корректность нарезки, а не содержание закона — оно берётся из официального источника.
- Целостность при передаче по HTTP: изменения текста закона проходят ревью в PR как git-дифф;
  `sha256` фиксирует текст на момент импорта.
- ПП № 1119 и приказы РКН — отдельная задача T2.7 (импорт PDF с `publication.pravo.gov.ru`).

## Последствия

- \+ Тексты — официальные, в актуальной редакции, с датой; обновление базы — одна команда.
- \+ Тот же API даёт будущие редакции (152-ФЗ — с 01.03.2027) — основа проверки актуальности (T6.6)
  и предупреждений о грядущих изменениях.
- − API недокументирован: формат может измениться без предупреждения. Смягчение — проверка ответов схемами,
  понятная ошибка `source-unavailable` и тесты разбора на фикстурах.
- − HTTP без TLS: подмена текста в пути теоретически возможна. Смягчение — ревью диффа в PR перед слиянием.

## Отвергнутые варианты

- **Копирование текстов из КонсультантПлюс/Гаранта** — неофициальный источник (ADR-0007).
- **Ручная перепечатка** — медленно и с риском опечаток в тексте закона.
- **Разбор PDF для всех актов** — сложнее HTML без выгоды там, где есть актуальная редакция.
