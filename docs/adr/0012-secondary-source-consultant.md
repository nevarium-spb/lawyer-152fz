# ADR-0012. КонсультантПлюс — вторичный источник для актов без официального электронного текста

- Статус: принято (решение владельца, 2026-10-25); для ПП № 1119 заменён [ADR-0014](0014-official-source-government-ru.md) (2026-11-08), КонсультантПлюс остаётся запасным путём
- Дата: 2026-10-25
- Уточняет: [ADR-0007](0007-license-agpl-and-legal-content-policy.md), [ADR-0011](0011-official-source-actual-pravo.md)

## Контекст

Часть нужных актов недоступна в официальных электронных источниках. Проверено 2026-10-25 на примере
ПП РФ от 01.11.2012 № 1119 (требования к защите ПДн в ИСПДн):

- `actual.pravo.gov.ru` — нет: в базе только акты с изменениями после 01.07.2022, а ПП № 1119 не менялось;
- `publication.pravo.gov.ru` — нет: в 2012 г. постановления Правительства на портале не публиковались
  (за ноябрь 2012 там только указы Президента и федеральные законы);
- `government.ru`, `rg.ru` — поиск работает только через JavaScript, программно текст не получить.

Официальная публикация существует только в печати: «Российская газета» и Собрание законодательства РФ.
Текст акта не охраняется авторским правом (ст. 1259 ГК РФ), но база данных КонсультантПлюс как подборка
охраняется правом изготовителя БД (ст. 1334 ГК РФ), а его правила запрещают массовое копирование.

## Решение

- КонсультантПлюс — **вторичный источник** и только для актов, которых **нет** в официальных электронных
  источниках. Если акт появится на портале pravo.gov.ru, он переводится на официальный источник.
- Берётся **только текст самого акта**: собственные примечания, комментарии и справки КонсультантПлюс
  отбрасываются при разборе. Загрузка — по одному документу, с честным User-Agent проекта, а не массово.
- Норма помечается `sourceType: secondary`, `sourceUrl` ведёт на consultant.ru (белый список вторичных доменов),
  а поле `officialPublication` с реквизитами официальной публикации **обязательно**. Реквизиты сверяются
  по независимому источнику. Для ПП № 1119 они подтверждены по Гаранту: «Российская газета», 07.11.2012,
  № 256; Собрание законодательства РФ, 05.11.2012, № 45, ст. 6257.
- Юрист обязан **раскрывать** вторичный источник в ответе: «текст по КонсультантПлюс; официальная
  публикация — …» (правило субагента, веха M4).
- Дата редакции вторичного источника задаётся вручную (у сайта нет API редакций). Для ПП № 1119 это дата
  подписания: в заголовке документа на consultant.ru нет пометки «ред. от …», то есть акт не изменялся.

## Последствия

- \+ В базе есть ключевые акты для аудита (уровни защищённости ИСПДн), без ручной перепечатки.
- \+ Пользователь всегда видит, что норма взята не из официального источника, и знает, где её официальная публикация.
- − Изменение акта не будет замечено автоматически по API редакций. Смягчение: повторный импорт показывает
  изменение текста в `git diff`; `pnpm kb:check` требует сверки не реже 180 дней.
- − Разметка сайта может поменяться — импорт упадёт с понятной ошибкой, разбор покрыт тестами.
- − Остаётся риск претензий правообладателя БД; смягчение — минимальный объём (единичные акты, только текст акта).

## Отвергнутые варианты

- **Только официальные источники** — ПП № 1119 и часть приказов РКН остались бы вне базы, аудит неполон.
- **Браузерная автоматизация government.ru / rg.ru** — хрупко и не гарантирует результат для всех актов.
- **КонсультантПлюс как основной источник** — неофициальный текст там, где есть официальный (ADR-0007).
