# ADR-0001. Ядро детерминировано, рассуждает LLM-хост

- Статус: принято
- Дата: 2026-10-23

## Контекст

Агент должен работать в трёх оболочках: плагин Claude Code, любой MCP-клиент, Telegram-бот (фаза 2).
Юридические ответы должны быть проверяемыми: ссылка на несуществующую или устаревшую норму — главный риск продукта.
Плагин должен работать без отдельного API-ключа.

## Решение

Ядро (`packages/*`) не вызывает LLM. Оно отдаёт факты: тексты норм с датами редакций, результаты сканирования,
находки правил, заполненные шаблоны. Рассуждение, диалог и итоговый текст делает модель хоста через MCP-инструменты.

Правило цитирования: текст нормы в ответе модель берёт только из `get_norm`. Субагент и скиллы обязаны это соблюдать.

## Последствия

- \+ Ядро тестируется быстрыми детерминированными тестами без токенов.
- \+ Плагину не нужен API-ключ; бот подключит то же ядро через Claude Agent SDK.
- \+ Галлюцинации норм ограничены: цитата проверяема по `NormId`.
- − Качество итогового ответа зависит от промптов субагента и скиллов; их проверяют evals (`evals/`).
- − Эвристики, требующие суждения (полнота текста политики), помечаются `confidence: needs-review` и дорабатываются моделью.

## Отвергнутые варианты

- **LLM внутри ядра (вызовы Anthropic API из сервера)** — нужен ключ и деньги у каждого пользователя плагина,
  недетерминированные тесты, двойная оплата при работе из Claude Code.
- **Только промпт без инструментов** — нормы из памяти модели могут быть устаревшими или выдуманными.
