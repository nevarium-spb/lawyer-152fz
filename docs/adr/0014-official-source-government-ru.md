# ADR-0014. Официальный сайт Правительства РФ — источник ПП № 1119 вместо КонсультантПлюс

- Статус: принято (решение владельца, 2026-11-08)
- Дата: 2026-11-08
- Заменяет в части ПП № 1119: [ADR-0012](0012-secondary-source-consultant.md)
- Уточняет: [ADR-0011](0011-official-source-actual-pravo.md)

## Контекст

Перед переводом репозитория в публичный проверен состав базы норм. Тексты 152-ФЗ, ст. 13.11 КоАП и
ПП № 687 взяты с официального портала, а 17 пунктов ПП РФ от 01.11.2012 № 1119 — из КонсультантПлюс
(вторичный источник, ADR-0012). Подборка КонсультантПлюс охраняется правом изготовителя базы данных
(ст. 1334 ГК РФ), а проект публичный и распространяется под AGPL, поэтому риск претензий правообладателя
не оправдан, если есть официальный источник.

Проверено 2026-11-08:

- `actual.pravo.gov.ru` и `publication.pravo.gov.ru` постановления 1119 по-прежнему не содержат (вывод
  ADR-0012 подтверждён: в 2012 г. постановления Правительства на портале не публиковались);
- официальный сайт Правительства РФ `government.ru` содержит полный текст:
  `http://government.ru/docs/all/84743/` (страница документа, текст в разметке без JavaScript);
- текст всех 17 пунктов с `government.ru` совпал с хранившимся в базе (сверка по нормализованным
  пробелам; `sha256` пунктов после импорта не изменились). Отличия разметки: сайт теряет надстрочный
  индекс («статьи 18¹» отдаётся как «статьи 181») и оставляет пробел перед запятой и точкой после
  закрывающей скобки.

## Решение

- Источник ПП № 1119 — страница `government.ru/docs/all/84743/`. Домен уже входит в белый список
  официальных (ADR-0011), норма получает `sourceType: official`.
- Это текст на сайте органа, принявшего акт, **не официальное опубликование**: официальное опубликование
  — «Российская газета», 07.11.2012, № 256; Собрание законодательства РФ, 05.11.2012, № 45, ст. 6257. Эти
  реквизиты обязательны в метаданных (`officialPublication`) и показываются в ответе `get_norm`
  («текст на сайте, не официальное опубликование»). Юрист называет источник и реквизиты в ответе.
- Разбор — `src/government/` (клиент и парсер на тех же принципах, что у остальных источников):
  только текст документа, один документ, честный User-Agent. Единственная правка текста — возврат
  индекса в ссылке «статьи 18.1 Федерального закона»; она покрыта тестом и не затрагивает других «181».
- Загрузка по HTTP: с TLS-рукопожатием сайт из Node отвечает нестабильно (соединение сбрасывается).
  Целостность — ревью `git diff` и `sha256` пунктов, как у `actual.pravo.gov.ru` (ADR-0011).
- Дата редакции — дата акта (2012-11-01): у сайта нет API редакций. Проверка актуальности по API
  невозможна, `check_norm_freshness` честно возвращает `unknown` с реквизитами публикации; `pnpm kb:check`
  по-прежнему требует сверки не реже 180 дней.
- Код КонсультантПлюс (клиент, разбор, тип `secondary`, правило раскрытия) остаётся запасным путём на
  случай акта, которого нет ни на pravo.gov.ru, ни на government.ru. Сейчас ни одна норма базы его
  не использует.

## Последствия

- \+ В базе нет текстов, взятых из коммерческой правовой системы.
- \+ Ответы по ПП № 1119 раскрывают реальный источник и реквизиты печатной публикации.
- − У ПП № 1119 нет автоматической проверки актуальности. Смягчение: сверка не реже 180 дней, повторный
  импорт показывает изменения текста в `git diff`.
- − Разметка сайта может измениться: импорт упадёт с понятной ошибкой, разбор покрыт тестами.
- − Правка надстрочного индекса зашита в разбор; если сайт начнёт отдавать «18.1» сам, правка перестанет
  срабатывать и ничего не испортит.

## Отвергнутые варианты

- **Оставить КонсультантПлюс** — риск претензий правообладателя БД в публичном репозитории.
- **Перепечатать текст по печатной публикации вручную** — ручной ввод, выше риск опечаток, нет источника
  для автоматической сверки.
- **Убрать ПП № 1119 из базы** — аудит уровней защищённости ИСПДн остался бы без нормы.
