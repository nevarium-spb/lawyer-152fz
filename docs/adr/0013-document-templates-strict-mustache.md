# ADR-0013. Шаблоны документов — подмножество Mustache со своим строгим рендерером

- Статус: принято
- Дата: 2026-10-29
- Закрывает: T6.1 в [PLAN.md](../PLAN.md)

## Контекст

Пакет `documents` заполняет шаблоны (политика обработки ПДн, согласия, уведомления в РКН) данными `OperatorProfile`.
Требования из плана и ADR-0007:

- **В шаблоне нет логики.** Юрист читает шаблон как обычный текст и правит формулировки, не разбираясь в коде.
- **Изменение текста видно в диффе.** Шаблон — отдельный файл Markdown, эталоны рендера лежат в репозитории.
- **Ни одного пустого места в документе.** Опечатка в имени поля должна ронять тест, а не давать документ
  с пропуском там, где должно стоять наименование оператора.
- Сервер поставляется одним файлом без `node_modules` (ADR-0005); новые зависимости — только последние версии
  (ADR-0009).

Кандидаты (npm, 2026-10-29):

| Пакет        | Версия | Зависимости                                                    | Последний релиз | Логика в шаблоне             |
| ------------ | ------ | -------------------------------------------------------------- | --------------- | ---------------------------- |
| `mustache`   | 4.2.0  | нет                                                            | 2021            | нет                          |
| `handlebars` | 4.7.10 | `minimist`, `wordwrap`, `neo-async`, `uglify-js`, `source-map` | 2026            | хелперы, `if`/`else`, `each` |
| `eta`        | 4.6.0  | нет                                                            | 2026            | произвольный JS              |

## Решение

1. **Синтаксис — подмножество Mustache:** `{{поле}}`, `{{объект.поле}}`, секции `{{#список}}…{{/список}}`
   (повтор для каждого элемента или вывод при истинном значении), инвертированные секции `{{^список}}…{{/список}}`
   (вывод при пустом списке или ложном значении), `{{.}}` — текущий элемент списка строк, `{{! комментарий }}`.
   Больше ничего: ни хелперов, ни партиалов, ни сравнений. Юрист видит текст и метки в фигурных скобках.
2. **Рендерер свой, около сотни строк, без зависимостей,** и он строгий:
   - неизвестное имя → ошибка с именем и номером строки, а не пустая строка;
   - незакрытая или перепутанная секция → ошибка разбора;
   - подстановка значения-объекта или списка в `{{поле}}` → ошибка.
3. **Экранирование под Markdown.** Значения из профиля экранируются обратным слэшем для служебных символов
   Markdown и HTML (`\`, `*`, `_`, `` ` ``, `[`, `]`, `<`, `>`, `#`, `|`): название «Рога_и*копыта» не превратит
   текст в курсив, а `<script>` из профиля не станет разметкой, если документ опубликуют на сайте.
   Тройных скобок `{{{ }}}` нет — неэкранированной подстановки не бывает.
4. **Шаблон — файл `packages/documents/templates/<id>.md`** с заголовком-метаданными (`title`, `normRefs`).
   Файлы вшиваются в бандл так же, как база норм (`define` при сборке, ADR-0005); при запуске из исходников
   читаются с диска.
5. **Проверки при сборке и в тестах:** каждый шаблон разбирается, каждое имя в нём сверяется с представлением
   эталонного профиля, каждая ссылка `normRefs` существует в базе норм. Golden-тесты рендерят каждый шаблон
   на эталонных профилях и сравнивают с файлами в `packages/documents/test/golden/`.

## Последствия

- \+ Пропуск в документе невозможен: опечатка в метке находится тестом, а не пользователем.
- \+ Нет зависимости с последним релизом в 2021 году и нет пяти транзитивных зависимостей Handlebars.
- \+ Синтаксис узнаваем: это Mustache, документация к нему общедоступна.
- − Свой код разбора нужно покрыть тестами самим.
- − Условий «если ИП, то …» в шаблоне нет. Варианты текста готовит код представления заранее: шаблон
  получает уже выбранную формулировку или флаг для секции.

## Отвергнутые варианты

- **`mustache`** — последний релиз 2021 года; неизвестная метка молча становится пустой строкой, и это не
  настраивается без обхода дерева токенов.
- **Handlebars** — логика в шаблоне (хелперы, `if`/`else`) и пять транзитивных зависимостей.
- **Eta, шаблонные строки JS** — шаблон становится кодом; юрист не может править его как текст.
