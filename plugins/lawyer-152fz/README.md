# Плагин lawyer-152fz для Claude Code

ИИ-юрист по 152-ФЗ «О персональных данных» и работе с Роскомнадзором.

## Установка

```
/plugin marketplace add nevarium-spb/lawyer-152fz
/plugin install lawyer-152fz@lawyer-152fz
```

Нужна последняя версия Node.js (сейчас ≥ 26): MCP-сервер плагина запускается через `node`.

## Что внутри

| Компонент                 | Назначение                                                           |
| ------------------------- | -------------------------------------------------------------------- |
| субагент `lawyer-152fz`   | отвечает на вопросы, цитирует нормы с датами редакций                |
| скилл `pd-consult`        | срабатывает на вопросы о персональных данных и передаёт их субагенту |
| скилл `pd-audit`          | проверяет сайт или код проекта и объясняет отчёт                     |
| MCP-сервер `lawyer-152fz` | поиск норм, аудит и база норм (вшита в `server/index.mjs`)           |

Инструменты сервера:

| Инструмент       | Что делает                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `search_norms`   | ищет нормы 152-ФЗ, ст. 13.11 КоАП, ПП № 687 и № 1119                                                |
| `get_norm`       | полный текст нормы с датой редакции — единственный источник цитат                                   |
| `audit_site`     | обходит сайт (до 50 страниц) и проверяет формы, согласия, политику, HTTPS, сервисы                  |
| `audit_html`     | проверяет страницу SPA по DOM из браузера (React, Vue — их формы не видны без браузера)             |
| `audit_codebase` | читает исходники (только чтение, без `.env`) и ищет иностранные SDK, облака за рубежом, ПДн в логах |

## Примеры

> Нужно ли согласие на обработку персональных данных для формы обратной связи на сайте?

Ответ содержит цитаты норм с идентификаторами вида `152-fz/art-9/part-1`, их можно проверить через `get_norm`.

> Проверь сайт https://example.ru на соответствие 152-ФЗ.

Отчёт: нарушения → риски → рекомендации, у каждой находки — где (страница и форма), что сделать и основание.
Отдельно — что проверить не удалось. Правки в проекте Claude делает только с вашего согласия.

Для сайтов с частными адресами (свой dev-сервер на `localhost`) аудит разрешён по умолчанию;
чтобы запретить, задайте переменную окружения `LAWYER_ALLOW_PRIVATE_NETWORKS=false`.

Результат носит справочный характер и не заменяет консультацию юриста.
